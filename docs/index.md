# Гайд для новичков Black Desert

Пошаговый маршрут для тех, кто впервые запускает Black Desert и хочет избежать типичных ошибок на старте.

Материалы основаны на серии видеогайдов Dr DozA, переработаны в текстовый формат и снабжены ссылками на исходные ролики и таймкодами.
